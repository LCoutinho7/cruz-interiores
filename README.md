# Cruz Interiores

Site institucional da Cruz Interiores — React 19 + TypeScript + Vite + Tailwind CSS + GSAP.

## Rodando localmente

**Pré-requisitos:** Node.js

1. Instalar dependências:
   `npm install`
2. Rodar o app:
   `npm run dev`

## Build

`npm run build`

## Deploy

O deploy para o GitHub Pages é feito automaticamente via GitHub Actions (`.github/workflows/deploy.yml`) a cada push na branch `main`.
